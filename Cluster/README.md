# ClusterFL

This repository contains the code and resources for **ClusterFL: A similarity-aware federated learning system for human activity recognition**.

## Overview
ClusterFL is a federated learning framework designed to improve the performance of human activity recognition models by clustering clients based on their data similarity. This approach addresses the challenges of data heterogeneity in federated environments.

## Repository Structure
- `ipynb/`: Contains the main Jupyter Notebook (`ClusterFL_a_similarity_aware_federated_learning_system_for_human_activity_recognition.ipynb`) demonstrating the implementation and experiments.
- `Results/`: Includes charts, convergence graphs, and accuracy metrics derived from the experiments.
- `Dataset/`: Data used for the experiments.
- `Paper/`: Documentation and the related research paper.

## Getting Started
1. Clone the repository.
2. Install the necessary dependencies (e.g. from `package.json` if using Node.js tools or typical Python data science libraries for the notebooks).
3. Open the Jupyter Notebook in the `ipynb/` directory to run the experiments.
